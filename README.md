Allowed options:

-h [ --help ]               Show help  
--include arg               Include directories  
--exclude arg               Exclude directories  
--scan-level arg (=1)       Scan level  
--min-file-size arg (=1)    Min file size to scan  
--file-mask arg             File mask  
--block-size arg            File compare block size  
--hash-algorithm arg (=md5) Hash algorithm
